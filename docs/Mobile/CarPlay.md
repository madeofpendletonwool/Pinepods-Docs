# CarPlay (iOS)

The iOS app works with Apple CarPlay. Install it from the [App Store](https://apps.apple.com/us/app/pinepods/id6751441116), sign in to your server, and connect your iPhone to the car. Pinepods appears with the other audio apps.

The CarPlay screen has these tabs:

| Tab | |
|---|---|
| **Now Playing** | The current episode. |
| **Current** | Episodes you're in the middle of. |
| **Saved** | Your saved episodes. |
| **More** | **Queue**, **Downloads**, **History**, **Podcasts** and **Playlists**. |

The car's controls, the steering-wheel buttons and the lock screen all control the same playback. Skipping forward and back uses the **Fast-forward interval** and **Rewind interval** from the app's **Settings**.

Download episodes before a drive (see [Downloads](../Features/Downloads.md#device-downloads-mobile)) so playback doesn't depend on mobile signal.
