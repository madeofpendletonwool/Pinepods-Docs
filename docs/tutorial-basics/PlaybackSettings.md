# Playback Settings

Each user sets their playback defaults under **Settings → Playback Settings**. Each value has its own **Save** button.

| Setting | Range | Default | What it does |
|---|---|---|---|
| **Default Playback Speed** | 0.5x–3.0x, in steps of 0.1 | 1.0x | The speed new episodes start at. A podcast's own playback speed, set on its page, takes precedence. |
| **Auto Complete Episode Threshold** | 0–3600 seconds | 0 | Episodes with this many seconds or less left are marked as complete, so you don't have to sit through the outro. `0` turns it off. |
| **Default Volume** | 0–100% | 100% | The volume new episodes start at. |
