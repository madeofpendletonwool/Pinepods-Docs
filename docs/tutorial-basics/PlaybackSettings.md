# Playback Settings

Each user sets their playback defaults under **Settings → Playback → Playback Settings**. Each number has its own **Save** button; **Add to queue position** and **Queue new episodes of new subscriptions** save as soon as you change them.

| Setting | Range | Default | What it does |
|---|---|---|---|
| **Default Playback Speed** | 0.5x–3.0x, in steps of 0.1 | 1.0x | The speed new episodes start at. A podcast's own playback speed, set on its page, takes precedence. |
| **Auto Complete Episode Threshold** | 0–3600 seconds | 0 | Episodes with this many seconds or less left are marked as complete, so you don't have to sit through the outro. `0` turns it off. |
| **Default Volume** | 0–100% | 100% | The volume new episodes start at. |
| **Add to queue position** | Bottom of the queue, or Top (play next) | Bottom | Where **Queue Episode** puts an episode. Hover **Queue Episode** in an episode's menu to use the other end once. See [The Queue](../Features/Queue.md). |
| **Queue new episodes of new subscriptions** | On or off | Off | Podcasts you subscribe to from now on start with **Auto-add new episodes to queue** on. Their back catalogue isn't queued, only episodes that arrive later. Podcasts you already have keep their own setting. In the mobile apps it's under **Settings → Playback**. See [The Queue](../Features/Queue.md). |
