# Display Settings

**Settings → Display Settings** holds a few per-user choices about how the web app looks and where it opens. They're saved to your account.

| Setting | What it does |
|---|---|
| **Select a start page** | The page you land on after signing in: Home, Feed, Search, Queue, Saved, Downloads, People Subscriptions or Podcasts. Click **Apply Start Page** to save it. |
| **Podcast Cover Display** | **Always use podcast covers instead of episode covers.** Some feeds give every episode its own artwork; turn this on to show the podcast's cover everywhere instead. Each podcast's own settings can override it. |
| **Avatar** | **Show my Gravatar.** Shows your [Gravatar](https://gravatar.com) as your avatar in the sidebar. Off by default, because it loads an image from gravatar.com using a hash of your email. |
| **Collection add mode** | How **Add to Collection** behaves in an episode's menu: **Modal picker** opens a dialog, **Sub-menu flyout** lists your collections in the menu itself. See [Collections](../Features/Collections.md). |
