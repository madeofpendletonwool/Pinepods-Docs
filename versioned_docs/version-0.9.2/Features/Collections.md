# Collections

Collections are named groups of episodes you put together yourself: "Episodes to share", "Interviews", "Recipes", whatever you like. **Saved** is the first collection; it's always there and can't be deleted, and **Save Episode** adds to it.

Open them from **Collections** in the sidebar. Each collection is a tab, with search, sorting (**Newest First**, **Oldest First**, **Shortest First**, **Longest First**, **Title A-Z**, **Title Z-A**) and filters for **Completed** and **In Progress** episodes.

Collections are on the web and desktop apps. The mobile apps show the **Saved** collection.

## Making a collection

Click **New collection** and give it a **Collection name**, and optionally a **Description** and an **Icon**. Use the edit button on a collection to change these later, or **Delete collection** to remove it. Deleting a collection doesn't delete its episodes.

## Adding episodes

Open an episode's three-dot menu and choose **Add to Collection**. Tick a collection to add the episode, untick it to take it out; changes apply straight away. You can create a new collection from there too.

How that menu works is set under **Settings → Display Settings → Collection add mode**: **Modal picker** opens a dialog, **Sub-menu flyout** lists your collections inside the menu.

## Adding episodes automatically

**Auto-add by category** in a collection's settings fills it from your podcasts' categories. Pick one or more categories, and every new episode from a podcast in any of them is added as it arrives. Tick **Add existing matching episodes now** to also add the episodes you already have.

Categories come from the podcasts' feeds; the list shows the ones your podcasts use.

## RSS feeds

Each collection can also be published as an RSS feed, to listen to it in another podcast app. See [RSS Feeds](../tutorial-extras/RSSFeeds.md).
